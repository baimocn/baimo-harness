## 模块 1 · 闲时队列（M-14）— 提交 `511ce9f`

机制一句话：宿主层 `IdleQueueStore`（落盘队列）+ `IdleQueueRunner`
（1.5s 节拍、执行器可注入）；「闲时」口径 = 宿主无任何 live 会话
处于 busy（SessionHandle.busy ← agent 状态事件）；每条任务的执行
就是目标会话的 `SessionHandle.prompt` 本身——检查点自动打点、成本
入账、预算熔断全部原样生效，不存在第二条执行通道。

- 默认关闭（D-01：未显式开启绝不自启）；开启后仅在全宿主空闲时
  按序取队首执行；状态机 queued/running/done/failed/blocked，
  每步落盘；进程重启时遗留 running 一律转 failed 并注明中断，
  绝不假装完成。
- 熔断显形：执行结果为 `budget_fused` 或启动即 `BUDGET_EXCEEDED`
  → 该条标 blocked 并**停住整条队列**并给出原因，不跳过、不硬闯；
  审批阻塞走既有审批门（队列任务同样弹审批卡）。
- 前台优先：前台会话开始发送时，先让路正在跑的闲时任务（abort
  其运行并重新入队、注明让路原因）；让路接口只在真的注册了中断
  回调时才报告成功，不假装让路。
- UI：右侧「闲时」页签（入队表单、队列列表含状态/上移/移除、
  启用开关、清完成项）+ 状态栏闲时摘要；闲时新建的会话不抢焦点。
- E2E 新增：宿主 5 条（顺序执行+落盘状态、默认关闭不自启、熔断
  blocked+停队列、前台让路、重启中断显形）+ 桌面 1 条（面板入队→
  开启→自动执行完成、状态栏计数、落盘断言）。
- 回归：83/83（node 70/70 + 桌面 13/13）。
- 截图：`m1-idle-queued.png`、`m1-idle-done.png`。
- 如实降级：队列排序仅「上移一位」按钮（无拖拽）；让路粒度为
  中断当前运行（Pi abort 语义）——被让路的任务原位回到 queued
  并注明让路原因（不掉队尾），全局空闲后自动续跑。

## 模块 2 · 插件目录（M-15）— 提交 `a9d7292`

机制一句话：`PluginService` 扫描数据目录 `plugins/*.mjs|*.js`，
可选 sidecar `<名>.plugin.json` 提供名称/版本/说明；启停状态落盘
`plugins.json`（默认全启用）；启用集合经 `--extension` 挂到每个
新建/续接的 Pi 会话；校验两层——静态层 `node --check` 语法检查 +
sidecar 校验（结果进条目 error 字段），运行时层以 Pi 自己的扩展
加载为准（失败时进程启动即非零退出，错误点名文件与原因，经宿主
PiProcessError → IPC → 界面顶部警示条全程不吞）。

- 示例插件：`apps/agent-host/plugins-examples/echo-plugin.mjs`
  （注册 `plugin_echo` 工具）+ sidecar 元信息。
- E2E 新增：宿主 3 条（扫描/sidecar/语法错误显形/启停落盘重启
  生效；启用插件时工具真实可用且结果回注模型 vs 停用时「Tool
  not found」的对照；工厂抛错插件使开会话显式失败并点名）+
  桌面 1 条（面板列出示例插件与红色点名的坏插件；停用坏插件后
  新会话里 plugin_echo 真实执行；停用示例插件后新会话报工具
  不存在）。
- 回归：87/87（node 73/73 + 桌面 14/14）。
- 截图：`m2-plugins-panel.png`、`m2-plugin-tool.png`。
- 如实降级：启停对**已打开**的会话不热生效（Pi 扩展在进程启动
  时加载），只影响新建/续接的会话——面板文案已明示此口径；
  语法校验结果按文件 mtime/大小缓存。
- 过程事故（已修复并加固）：新桌面 E2E 首跑在整套并行下启动
  超时（30s 等待不够）且失败路径漏关 Electron 进程拖死整套；
  已把两份新桌面测试的启动等待放宽到 90s、launchApp 失败必关
  进程并清目录。

## 模块 3 · 会话回放 — 提交 `b4f1df5`

机制一句话：`ReplayCursor`（packages/ui 纯逻辑）对落盘归一化事件
序列做前缀折叠——任意下标的画面 = 把该前缀喂给与实时流**同一个**
归约器 `applyHostEvent` 的结果，前进增量折叠、后退/跳转重折前缀，
不存在第二套渲染口径；游标只读事件数组，不调用任何桥接/落盘/
运行接口。

- UI：会话上方「回放本会话」入口；回放控制条（播放/暂停、上下
  单步、进度拖动、0.5×/1×/2×/4× 倍速、事件计数、退出）；回放中
  输入区禁用并注明只读，计划卡/审批卡隐藏，切会话/新建自动退出。
- E2E 新增：ui 单测 3 条（任意下标与从头折叠严格一致的逐点对账、
  关键节点内容、空序列）+ 桌面 1 条（真实运行后进回放：起点
  画面为空、单步 3 步、4 倍速播到结尾画面与实时一致；**只读
  铁证**：回放前后落盘 eventCount 与桩请求数严格不变；退出后
  原执行流恢复、输入区可用）。
- 回归：91/91（node 76/76 + 桌面 15/15）。
- 截图：`m3-replay-mid.png`、`m3-replay-end.png`。
- 如实降级：无。
